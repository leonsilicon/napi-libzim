# Project Environment

Node.js native library; not React Native, native iOS, or native Android. No device QA needed.
Uses pnpm via Vite+ (`vp install`, `vp check`, `vp test`). Native code uses Rust/napi-rs and a C++17 cxx bridge.
`vp run build:deps` builds pinned libzim and dependencies using vcpkg; `vp run build` builds the binding and JS facade.
Binary content uses plain Uint8Array end-to-end, including napi-rs. There is no custom Blob export. String/ArrayBuffer/Buffer inputs remain supported, and custom providers return Uint8Array chunks. Byte helpers from uint8array-extras are bundled by Vite+; consumers have no JS runtime dependencies.
`vp run test:upstream` verifies pristine pinned upstream files, applies the reviewed import and Uint8Array adaptations generated by TypeScript AST codemods, and runs all 26 tests plus type checking. CI also runs the suite against clean npm installations. Regenerate the diff with `vp run patch:upstream`; review changes in `patches.gen`.
Release publishing uses npm OIDC (id-token: write), npm 11.21.0, and the GitHub `npm` environment restricted to `v*` tags. No token secret is referenced. One-time registry setup uses `vp run setup:trusted-publishing` after all six packages exist and npm login/2FA; claims are in `.github/npm-trusted-publisher.json`. Registry activation is separate from GitHub setup.

Published package names use `@leonsilicon/napi-libzim` and the five `@leonsilicon/napi-libzim-<platform>` packages. The binary filename and Rust crate remain `napi-libzim`. The user authorized the initial 0.1.0 publication and trusted publisher registration after CI succeeds. An earlier unscoped bootstrap published only `napi-libzim-darwin-arm64@0.1.0`; publication was stopped when the user requested the scope.
