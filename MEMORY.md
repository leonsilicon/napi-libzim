# Project Environment

Node.js native library; not React Native, native iOS, or native Android. No device QA needed.
Uses pnpm via Vite+ (`vp install`, `vp check`, `vp test`). Native code uses Rust/napi-rs and a C++17 cxx bridge.
`vp run build:deps` builds pinned libzim and dependencies using vcpkg; `vp run build` builds the binding and JS facade.
`vp run test:upstream` verifies pristine pinned upstream files, applies the reviewed import patch generated by a TypeScript AST codemod, and runs all 26 tests. CI also runs the suite against clean npm installations. Regenerate the diff with `vp run patch:upstream`; review changes in `patches.gen`.
